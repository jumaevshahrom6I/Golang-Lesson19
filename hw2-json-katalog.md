# ДЗ — Урок 20: JSON

## Задание 1. Каталог товаров с JSON-хранилищем
Консольная программа. Меню:
```
1. Добавить товар
2. Показать все
3. Найти по категории
4. Удалить по ID
5. Сохранить и выйти
```

Требования:
1. Структуры `Category`, `Product` (внутри `Category`) и `Catalog` (список товаров + следующий ID).
2. Теги: имена в snake_case; `omitempty` для описания; `json:"-"` для себестоимости (`CostPrice`) — она не должна попадать в файл.
3. Данные хранятся в `catalog.json`: загружаются при старте, сохраняются при выходе.
4. Если файла нет — программа стартует с пустым каталогом и **не падает**.
5. Все ошибки проверяются и оборачиваются с контекстом через `%w`.

**Готово, когда:** данные сохраняются между запусками, в `catalog.json` нет себестоимости, программа не падает без файла.

## Задание 2. Погода или пользователи из API
Возьмите любой бесплатный API без ключа, например:
- `https://jsonplaceholder.typicode.com/posts?_limit=10`
- `https://jsonplaceholder.typicode.com/comments?postId=1`

1. Опишите структуру под ответ.
2. Сделайте запрос, проверьте `err` и `StatusCode`.
3. Разберите JSON в срез структур и выведите красиво.
4. Сохраните результат в файл `result.json` через `MarshalIndent`.
